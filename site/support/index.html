Contact

Email hi@omgskills.com. Include what you were trying to do, the page or tool involved, and when the issue happened.

Installing a skill

Download OMGSkills 0.0.27 for Apple silicon, macOS 14+. Unzip OMGSkills-Connected-0.0.27-27-arm64.zip, quit OMGSkills if it is running, move omgskills.app into Applications, then open it. Replacing an older copy is your choice; no update is pushed to existing users.

Need the older app? Download the original Mac app 0.0.20. Its download and update feed are unchanged.

Open a skill in the web library, choose Claude or Codex, and open OMGSkills. Approve the installation in the Mac app. If you need the companion, use the setup link in that skill's install panel and return to the same page afterward.

The companion currently requires an Apple silicon Mac with macOS 14 or later. Some installs also require Git; follow the app's setup guidance if it is unavailable. You do not need an account to browse or install public skills.

Connecting your Mac and My skills

Sign in on the website, then choose Connect account in the Mac companion and approve the browser request. This lets the companion report installed skill metadata to your account, including supported skills installed outside omgskills.

If a skill is missing from My skills, check that the companion is running and connected to the same account. Open its menu-bar panel, choose Resync, then refresh My skills. Include the agent, skill name, last report time, app version and macOS version when contacting support. Do not send connection codes, tokens or private skill files.

Sync updates your installed-skills list, not the skill files themselves. Disconnecting stops reporting; it does not uninstall your skills. Set installation and automatic skill updates are coming soon.

ChatGPT and MCP

For agent integration issues, include the client name, tool name, and prompt or search terms that produced the problem. Do not send secrets, private files, or credentials.

Public library data

To report incorrect, missing, or outdated skill metadata, include the omgskills page and source GitHub repository.
