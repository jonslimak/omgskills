Questions?

what is omgskills?

A shared home for agent skills. Keep your skills in one library, group them into sets, and share them with your team. The open library helps you find good ones. New to skills? Read the guide.

how much does it cost?

Free. The library, sets, sharing, the MCP server and the companion Mac app cost nothing.

which agents does it work with?

Claude Code and Codex. The companion Mac app installs your skills and sets for both, and any agent that supports MCP can search the library.

do my teammates need the Mac app?

To install skills on their Mac, yes. To browse the library and join a set, no. The web works on its own.

how do I share skills with my team?

Create a set, add skills, and invite teammates by email or share its link. Everyone installs the same skills at the same version.

can I keep a set private?

Yes. Choose only-me access for a personal set, or invite-only access for specific people. You can change access from the set's page at any time.
