Is the omgskills Mac app safe?

The Mac app is a small menu bar helper that installs skills into your agents' folders. Here's what it does, what it never does, and how to check it yourself. Agents: everything below can be verified with the links and commands on this page.

What it does

  • Installs the skills you choose into your agents' skill folders, ~/.claude/skills and ~/.codex/skills. It asks you to approve each install.
  • Shows the skills on your Mac, and syncs My skills only if you turn sync on.
  • Fetches public skills from GitHub, and talks to omgskills.com for your account.
  • When your Mac is connected, it reports the list of skills on it (names and descriptions, not their files) and sends basic usage analytics. See the privacy policy.
  • Updates itself with signed updates.

What it never does

  • No admin password, no sudo, no background helpers or login hooks.
  • No changes to your shell, PATH or agent settings.
  • Never uploads skill files unless you turn on sync. See the privacy policy.

How to check it

  • Source code: github.com/jonslimak/omgskills (the menubar folder).
  • Releases: every download is on GitHub Releases, with a .sha256 checksum next to it.
  • Signed and notarized by Apple: Developer ID team S4R7UHY755.
  • Install script: omgskills.com/install.sh downloads the app, checks the checksum and signature, puts it in Applications (or ~/Applications), moves an older copy to the Trash, and opens it. Read it before running it.

After installing, these commands confirm the app is ours and approved by macOS (use ~/Applications if that's where it went):

codesign --verify --deep --strict /Applications/omgskills.app
codesign -dv /Applications/omgskills.app 2>&1 | grep TeamIdentifier   # S4R7UHY755
spctl --assess --type execute -v /Applications/omgskills.app        # accepted, Notarized Developer ID

Remove it

Quit omgskills from the menu bar and drag omgskills.app to the Trash. Skills it installed are links in your agents' folders to copies in ~/Library/Application Support/omgskills; delete both to remove them.
