Video transcript

How do you connect Stripe to Claude? Stripe already did the work. They publish official skills for Claude Code — instruction files your agent loads when relevant, that teach it how Stripe wants to be integrated. They work on Claude, Codex, Cursor, or any agent you're working with — they're free, and they install in seconds. These are the five worth having.

First, stripe-best-practices. This is the foundation. Adding payments means real decisions — Checkout Sessions or PaymentIntents, how to set up Connect, which integration fits your case. This skill gives Claude or Codex Stripe's own answers to those questions, so you get the recommended pattern instead of a plausible guess.

Second, connect-recommend. This is Stripe's most-starred skill, and it covers the part people find hardest: Stripe Connect. It guides charge patterns, Dashboard access, and platform setup, so if you're building anything with sellers, vendors, or an e-commerce platform, this is the skill that gets the configuration right.

Third, upgrade-stripe. Everyone has an API upgrade they've been putting off. This skill walks your agent through Stripe's version changes and SDK updates, so you can finish an upgrade in a single session.

Fourth — and here the video turns. create-payment-credential. The first three skills help your agent build your integration. This one is about what agents can do themselves: it gets secure, one-time-use payment credentials from a Link wallet, so an agent can complete a real purchase with a card that can only be used once.

Fifth, pay-for-http-request. This skill lets an agent pay for an API call while making it, using the x402 payment standard through a command-line tool called purl. When an agent hits a paid endpoint, it can pay and continue on its own.

All five are official Stripe skills — free, open source, and published by Stripe, not third parties. You can install any of them in one click at omgskills.com, where the library has seven more Stripe skills. They work on Claude, Codex, Cursor — or any agent you're working with. And that's how you connect Stripe to Claude Code.
