About omgskills

omgskills helps people and agents find useful skills from trusted public sources.

Public skill library

The web library brings together skills published in public GitHub repositories. Listings preserve source links and catalog metadata so visitors can inspect the original project before using a skill.

Editorial discovery

Featured creators and collections make the catalog easier to explore. Editorial placement helps with discovery; it does not replace the original repository as the source of truth.

Mac app

The free macOS app provides a focused way to search, read, install, and manage skills across supported agent workflows.

Agents and developers

Agents can use the read-only MCP server, public catalog manifests, and Markdown mirrors. Setup instructions and data links are available in developer resources.

Contact

Questions, corrections, and support requests can be sent to hi@omgskills.com.
