About omgskills

omgskills is a way to share skills across teams & agents. Keep your skills in one place, share them with your team, and use them in Claude, ChatGPT, Cursor, Grok, Muse and more.

My skills

My skills holds your own skills and the ones you add from the library. Turn on Sync My skills, and your connected Macs keep a private copy of each skill's files there, so you can see, restore and share them anywhere. You can also add a skill from a GitHub link or a folder on your computer.

Sets

A set brings the skills for a project or team together. Choose public, invite-only, or only-me access, share the link, and teammates install the whole set from the Mac app at the same version.

Mac app

The free Mac app installs skills and sets into Claude Code and Codex. With Sync My skills on, it keeps a private copy of your skills in My skills. Set installation is available now; automatic team skill updates are coming soon. Download the Mac app for Apple silicon, macOS 14+. The original Mac app 0.0.20 remains available; existing users are not automatically upgraded.

Your agents

Add the My skills MCP (https://omgskills.com/my/mcp) to Claude, ChatGPT, Cursor, Grok, Muse or any agent that supports MCP, then sign in. The agent can search and read your skills, read-only. The public Library MCP (https://omgskills.com/mcp) lets agents search the open library with no account. Setup instructions are in developer resources.

Open library

The library brings together skills published in public GitHub repositories, with featured creators and collections to make them easier to explore. Listings keep source links so you can inspect the original project before using a skill. Featured placement helps with discovery; the original repository stays the source of truth.
