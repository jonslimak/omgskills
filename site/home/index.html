Questions?

what is omgskills?

A library and workspace for agent skills. Find useful instructions from creators, organize your own library, and share sets with your team. New to skills? Read the guide.

how much does it cost?

The public skill library, MCP server, and Mac app are free to use.

which agents does it work with?

The Mac app helps you install skills for Claude Code and Codex. The public library can also be searched by agents that support MCP.

how do I share skills with my team?

Create a set in the web app, add skills, and choose public or invite-only access. Share the set's link with your teammates.

can I keep a set private?

Yes. Choose only-me access for a personal set, or invite-only access for specific people. You can manage access from the set's page.
