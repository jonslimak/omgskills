omgskills · Skill management

Add a skill once. Send it to every agent that needs it.

Your OMG is your personal skill library. Pick skills from the public library or add your team's private ones, then choose which agents get each skill. When teammates connect the same team agent, it gets the skills every one of them sends.

One library per person

Your OMG holds every skill you use, whether it came from the public library or from your team's private repos. Add a skill there once instead of installing it in each agent by hand.

Each agent gets its own set

Choose which skills go to ChatGPT, Claude, Hermes or any other agent. Your personal Claude can stay lean with just humanizer while ChatGPT gets three skills.

Team agents combine everyone's picks

When several people connect the same team agent, it receives the skills each person sends. Private skills only reach the agents their owner sends them to.
